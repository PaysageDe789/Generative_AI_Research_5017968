# Generative_AI_Research_5017968
enerative AI Research

This repository organises materials for the research project “Using Generative AI Tools: Boon or Bane”.

Folder Structure

literature/: Literature review materials and reading notes.

quantitative/: Survey questions, shareable datasets, analysis scripts, and quantitative analysis reports.

qualitative/: Interview guides, de-identified transcripts, and qualitative analysis findings.

drafts_reports/: Research proposals, paper drafts, and final reports.

additional_materials/: Shareable information sheets, photographs, and other media files.

File Naming

Use descriptive file names that identify the content, date, and version where relevant. Use dates in YYYY-MM-DD format and underscores instead of spaces.

Example: survey_questions_2026-09-13_v01.docx

Collaboration Guidelines

Pull the latest changes before editing files.

Place files in the appropriate folders and follow the naming convention.

Write meaningful commit messages explaining each change.

Use separate branches for proposed changes and request review before merging into the main branch.

Do not upload identifiable participant data or signed consent forms. Keep sensitive materials in restricted storage and confirm access arrangements with the project team.
